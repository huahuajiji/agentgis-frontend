## 1. 这一阶段做了什么

一句话：**把"6 个区、17 个面板、一半点了没反应"的半成品，收敛成"3 个区、每个按钮都有响应"的小而完整的工作台。**

没有加任何一个新功能。这一阶段全部是减法。

具体清单：

| 类别 | 删掉的东西 | 说明 |
|---|---|---|
| 探索 demo | `src/demos/` 整个目录 | MouseToolVueDemo（822 行）+ MouseToolTransitionDemo（1452 行），只挂在独立路由，界面上无入口 |
| 路由 | `/mousetool-vue-demo`、`/mousetool-transition-demo`、`/ai`、`/history`、`/settings` | 前两个是 demo，后三个是区壳 |
| 导航区 | AI / 历史 / 设置 | 三个区里所有面板都是虚线占位 |
| 左栏面板 | 视图设置、地图工具、版本、查找外部数据（半成品）、数据源、引用数据、导入队列、AI 对话、执行预览、上下文、执行记录、操作历史、接口配置、偏好设置 | 13 个占位 + 1 个半成品；连同 50 行高德 POI 常量一起删 |
| 检查器页签 | 参考、AI | 参考页签只有变体逻辑没有数据，AI 页签纯占位 |
| 组件 | `shared/PlaceholderBlock.vue` | 全项目无引用后删除 |
| 死样式 | `.fixed-ai-panel`、`.agent-actions`、`.side-scroll.with-fixed-ai` | 随 AI 面板块一起删 |

同时保留/调整的：

- 导航：**地图 / 项目 / 数据** + 账户按钮（账户弹窗是 BYOK 高德 Key 的真正入口）。
- 左栏：项目区（项目列表、图片资源）、数据区（GeoJSON 导入 / 导出）——三个真实现面板。
- 检查器：**要素 / 操作**两个页签（操作页签是撤销重做历史，核心叙事，必须留）。
- 地图区左栏空态：显示"这个区暂时没有面板。常用操作在中间的地图工作区和右侧检查器。"
- 路由模式：`createWebHistory` → **`createWebHashHistory`**（GitHub Pages 刷新兼容）。
- 新增 `.gitattributes`：`* text=auto eol=lf`，与个人站 giants-girdle 一致。

## 4. 这一阶段做出/暂缓的决策

| 决策 | 选择 | 理由 / 备注 |
|---|---|---|
| 地图区左栏空着怎么办 | 显示空态文案，**不自动收起** | 行为更可预期；想改成自动收起只需改 `DesktopShell.vue` 里 `sidebarCollapsed` 的初始值 |
| 「参考图层」页签 | **删** | V1 一条业务线用不到参考图层概念；数据模型与移动端暂未清理 |
| 「查找外部数据」半成品 | **撤** | 表单完整但按钮无反应，比占位更骗人；以后接高德 POI 搜索时再加 |
| 移动端 | **不动** | 不在本阶段范围；`MobileShell` 仍显示"参考图层"字样，编译正常 |
| 行尾 | 加 `.gitattributes` 统一 LF | 消除 Windows autocrlf 与沙箱差异造成的 diff 噪音 |

目标：给 `shared/mapDocument/` 的三个核心模块加 Vitest 单测，约 15–25 个用例。

| 模块 | 文件 | 测什么 |
